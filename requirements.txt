# requirements.txt — the product's complete dependency set.
#
# Pinned to the versions this build was developed and tested against, because a
# security tool whose behaviour changes on a transitive upgrade is not a tool
# anyone should trust. Regenerate deliberately, not incidentally.
#
#   python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
#   (or: uv venv .venv && uv pip install -r requirements.txt)
#
# WHAT IS DELIBERATELY ABSENT, AND WHY
#   fastapi, pydantic   Starlette alone serves this product; FastAPI's value is
#                       schema generation from type hints, which is not worth a
#                       dependency tree here.
#   sqlalchemy          the repository speaks parameterised SQL directly and is
#                       already Postgres-portable. An ORM would add a large
#                       dependency to hide SQL that is better read than hidden.
#   passlib, bcrypt     hashlib.pbkdf2_hmac is in the standard library, is the
#                       OWASP-listed choice, and adds no supply-chain surface.
#   httpx, requests     THIS IS THE IMPORTANT ONE. No outbound HTTP client is
#                       installed, so the product cannot make one. The HTTP
#                       tests drive the ASGI app directly through
#                       tests/asgi_shim.py instead of Starlette's httpx-backed
#                       TestClient. See tests/test_containment_outbound.py.
#   psycopg2            PostgreSQL is documented and gated off in this build.
#   reportlab           reports export as CSV, JSON and printable HTML.
#
# PANDAS IS PINNED BELOW 3.0 ON PURPOSE. pandas 3.0 changes timestamp flooring
# behaviour that src/features/windowing.py relies on for the fixed 5-minute
# window grid. Upgrading is a deliberate migration, not a version bump.
